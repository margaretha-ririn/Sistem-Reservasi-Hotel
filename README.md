# 🏨 Sistem Reservasi Hotel – Coer Hotel

Sistem Reservasi Hotel merupakan aplikasi berbasis web yang dikembangkan untuk memudahkan pengguna dalam melakukan pemesanan kamar hotel secara online.

Website ini menyediakan informasi tipe kamar, formulir pemesanan, pilihan fasilitas tambahan, serta halaman konfirmasi yang menampilkan rincian reservasi dan estimasi biaya.

## ✨ Fitur

- **Halaman Beranda**  
  Menampilkan informasi dan pengenalan Coer Hotel.

- **Daftar Kamar**  
  Menampilkan pilihan kamar hotel beserta foto, deskripsi, dan harga per malam.

- **Formulir Reservasi**  
  Memungkinkan pengguna mengisi data pribadi, memilih tipe kamar, menentukan tanggal check-in dan check-out, serta jumlah tamu.

- **Fasilitas Tambahan**  
  Pengguna dapat memilih layanan tambahan seperti sarapan, WiFi, antar jemput, kolam renang, gym, dan spa.

- **Metode Pembayaran**  
  Menyediakan pilihan metode pembayaran, yaitu transfer bank, kartu kredit, dan e-wallet.

- **Validasi Formulir**  
  Memeriksa kelengkapan data dan memastikan tanggal check-out setelah tanggal check-in.

- **Penyimpanan Data**  
  Menyimpan data pemesanan ke database MySQL.

- **Halaman Konfirmasi**  
  Menampilkan detail pemesanan, lama menginap, dan estimasi total biaya.

- **Cetak Konfirmasi**  
  Memungkinkan pengguna mencetak rincian pemesanan.
